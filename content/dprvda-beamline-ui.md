## Overview

Beamline UI is a set of React components and complete app screens (dashboards, data tables, settings, AI-agent,
voice and trading screens) that install into your own repository as editable source. It is built with React 19,
TypeScript, Tailwind CSS v4 and Radix.

## Features

- **Code you own** – parts land in your app as source files you can edit and commit.
- **shadcn registry** – the free parts install with the shadcn CLI, no account needed.
- **Coding agents** – a hosted MCP server lets Claude Code, Codex and Cursor find and install parts.
- **Pricing** – free MIT parts; the complete system is $49 one-time for one person, with lifetime updates.
