## Overview

ssych ui is a shadcn/ui registry of dark, data-dense React components for trading terminals, crypto exchanges, fintech apps and AI agent consoles: order book, depth chart, candlestick chart, market heatmap, order ticket, swap ticket, trade tape, holdings and positions tables. The components are free (MIT); full dashboard screens and landing pages are paid.

## Features

- Listed in the official shadcn registry directory as @ssych.
- React, TypeScript and Tailwind, dark first.
- Hand-drawn SVG charts with no chart library.
- The source lands in your repo.

## Installation

```bash
npx shadcn@latest add @ssych/order-book
```
