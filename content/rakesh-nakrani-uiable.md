## Overview

UIAble is an open-source library of reusable UI components built for developers who want practical, customizable building blocks for modern applications. No vendor lock-in, no unnecessary abstraction—just components you can own, adapt, and ship faster.

## Features

- **You own the code**: Every component is copied into your project. Nothing is hidden behind a package, so you can edit, customize, and maintain everything yourself.

- **Built for real products**: UIAble focuses on components you'll actually use in production from forms and tables to dialogs and accessibility not just components that look good in demos.

- **Tailwind without the mess**: We use Tailwind CSS in a clean and readable way, so components stay easy to understand and customize.

- **User-Friendly SetupNo lock-in**: Utilize the shadcn CLI or clone the repository to quickly set up your project and start managing components right away.

- **Open source from the start**: UIAble is completely open source. Everyone can use it, contribute to it, and help make it better.
