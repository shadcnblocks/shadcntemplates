## Overview

agentcn is a shadcn-compatible registry of production-ready AI agent recipes built on Eve and Flue frameworks. Zero config, one command setup, with live previews for each agent.

## Features

- **Zero config** – Works out of the box with sensible defaults
- **shadcn CLI** – Install with `npx shadcn@latest add @agentcn/eve/weather`
- **Eve & Flue powered** – Full access to powerful agent frameworks
- **Live previews** – Run each agent from its docs page
- **Complete recipes** – Instructions, tools, skills, and workflows
