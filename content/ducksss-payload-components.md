## Overview

Payload Components is a community-first source registry for Payload CMS page
blocks. Its 67 MIT components target Payload v3 with Next.js 15/16 and remain
fully editable after installation.

## Features

- **Source ownership** - Every component is copied into the consumer repository.
- **Automated Payload wiring** - The CLI registers Pages and RenderBlocks and
  regenerates Payload types and the admin import map.
- **Reviewable adoption** - Each install is an ordinary git diff.
