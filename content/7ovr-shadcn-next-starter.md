## Overview

7Ovr Landing Starter is a free, MIT-licensed Next.js template built with shadcn/ui and Base UI. It includes a complete landing page and clear conventions for coding agents.

## Features

- Prerendered pages with metadata, a sitemap and social sharing images.
- Light and dark themes, restyled with one shadcn preset.
- `CLAUDE.md`, `AGENTS.md` and bundled skills guide coding agents.
- Lint rules catch design drift; CI runs unit tests, browser checks and Lighthouse.
